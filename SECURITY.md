# Security Policy

## Supported Versions

Only the latest released version of virtual-lb is supported with security updates.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Report vulnerabilities using GitHub's private vulnerability reporting feature if available, or contact the maintainer privately.

Please include:

- A description of the issue
- Steps to reproduce
- Affected versions or commits
- Any known impact or workaround

## Disclosure

We aim to acknowledge reports within 7 days and coordinate disclosure once a fix is available.
